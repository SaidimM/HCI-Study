# Visual Design Curriculum
## Layout · Color · Typography · Aesthetics: the *felt* side of HCI

> *Attractive things work better.* — Don Norman, 2002

**Why this lives inside HCI.** Layout, color and type are how an interface (or a magazine) produces **trust, calm, delight and clarity**. HCI research on *aesthetics and emotion* asks exactly this, so this track is a research foundation, not a hobby.

```
┌────────────────────────────────────────────────────────────────────────┐
│                    VISUAL DESIGN INSIDE HCI                            │
├──────────────┬──────────────┬──────────────┬───────────────────────────┤
│   LAYOUT     │    COLOR     │  TYPOGRAPHY  │   AESTHETICS & EMOTION    │
│ where & how  │ what & how   │ how words    │ why it *feels* good and   │
│ much         │ it feels     │ look & read  │ whether that changes use  │
└──────────────┴──────────────┴──────────────┴───────────────────────────┘
        shared: [[visual-hierarchy]] · [[gestalt-grouping]] · [[contrast]]
                [[signifier]] · [[feedback]]   ← Norman links
```

## The learning loop
1. **Learn** a principle.
2. **Spot** it in a magazine or site → write a *teardown* (`20-notes/teardowns/`).
3. **Sketch** its structure over a screenshot.
4. **Recreate** it with different content.
5. **Record the editor's intention:** why this choice, and what breaks if it changes?

Rule of thumb: **1 principle → 3 teardowns → 1 recreation.**
